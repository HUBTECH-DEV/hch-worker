# Security Policy

Do not open public issues containing credentials, enrollment tokens, private keys, production manifests, internal endpoints, or exploitable vulnerability details.

Report security vulnerabilities privately through GitHub Security Advisories for this repository. Include the affected version, platform, reproduction steps, impact, and any proposed mitigation.

The public certificate and public verification keys are not secrets. Worker private identity keys, release signing keys, root signing keys, and one-time enrollment credentials must never be committed or attached to issues.
